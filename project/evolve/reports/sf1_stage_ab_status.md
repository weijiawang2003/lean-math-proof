## 1. What was implemented

- **`scripts/sf1_common.py`** (new) — shared deterministic utilities:
  `read_json_or_jsonl`, `write_jsonl`, `ensure_parent_dir`, `stable_hash`,
  `deterministic_sample`, `extract_decl_names_from_record` (dict-value **and**
  dotted-decl-name dict-**key** harvesting, depth-bounded), and
  `load_consumed_decl_names` (directories / globs / files; missing paths skipped
  into a ledger). A dotted-decl-name regex keeps tactic strings and prose out.
- **`scripts/sf1_extract_mathlib_catalog.py`** — real `--from-artifacts` mode
  that harvests the catalog universe from repo artifacts (discovered-theorem
  catalog + eval surfaces). Live traced-cache mode remains a documented TODO.
- **`scripts/sf1_filter_consumed_surfaces.py`** — rewritten to build the
  consumed-theorem set for real via `sf1_common.load_consumed_decl_names` and
  subtract it. Writes `frontier.jsonl`, `exclusion_ledger.json`, and a
  `consumed_decl_names.txt` dump.
- **`sf1_batch_policy.json`** — `catalog_sources` (discovered catalog + eval
  surfaces) and `exclude_consumed_surfaces` (routing target sets + project/data
  pools + tasks.py) point at the project's real theorem-name sources.
